# 📊 Pesquisa de Satisfação - TudoWeb

Este projeto faz parte das minhas atividades como **Técnico em Desenvolvimento de Sistemas**. O objetivo é coletar dados de satisfação de clientes para a empresa fictícia *TudoWeb* utilizando Python.

## 🚀 Funcionalidades
- Coleta de dados (Nome, Idade e Opinião).
- Utilização de **estrutura de repetição `FOR`** para gerenciar 50 entrevistas.
- **Estruturas de decisão (`if/elif`)** para filtrar as opiniões.
- Exibição de relatório final com a quantidade de respostas "Excelente" e "Ruim".

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Ambiente:** GitHub Web Interface

## 📝 Como funciona o programa
Ao rodar o script, o sistema solicita a opinião do usuário baseada em uma escala:
1. **EXCELENTE**
2. **BOM**
3. **RUIM**

Ao final das interações, o console exibe um resumo estatístico da pesquisa.
